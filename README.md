# HOA Fee Calculator

Free online tool to estimate Homeowners Association fees.

🌐 Live Site: https://www.hoafeecalculator.com

## What It Does

Helps homebuyers calculate:
- Monthly HOA fee estimates
- Annual cost breakdowns  
- Budget planning for home purchase

## Who Is It For

- First-time homebuyers
- Real estate investors
- Anyone buying in an HOA community

## Tech Stack

HTML, CSS, JavaScript
Deployed on Vercel

## Why I Built It

HOA fees catch many buyers off guard. This tool makes estimation simple and instant — no signup needed.
